# 基于时间的反死区

默认把摇杆输入强度从“输出幅度”改成“输出时间占比”：输入低于最低幅度时，脉冲期间沿原方向输出该幅度，其余时间归零；输入高于最低幅度时直接直通。这样小幅输入也能越过下游死区；若下游只是把低于死区的值截断、不缩放，长期平均强度仍与输入一致。若下游会重新缩放死区以上的输入，可开启“缩放型下游补偿”改用静态反死区映射。

## 原理

设输入强度为 `s`（向量长度），最低脉冲幅度为 `m`，实际幅度 `A = max(s, m)`，脉宽为 `p`：

```
占空比 = s / A
周期   = p / 占空比 = p × A / s
```

每个周期输出 `p` 毫秒的 `A` 幅度，其余时间归零，下游死区之前的平均输出为 `A × (s / A) = s`。

- `s < m`：`A = m`，按占空比 `s / m` 脉冲输出。
- `s ≥ m`：`A = s`，占空比 100%，直接直通；输入本身已高于死区，不再需要补偿。
- `s = m / 2`：脉宽等于等待间隔。

以默认 `m = 5%`、`p = 4 ms` 为例：

| 输入 | 实际幅度 | 占空比 | 输出 |
| --- | --- | --- | --- |
| 0.5% | 5% | 10% | 4 ms 输出 + 36 ms 等待 |
| 1% | 5% | 20% | 4 ms 输出 + 16 ms 等待 |
| 2.5% | 5% | 50% | 4 ms 输出 + 4 ms 等待 |
| 5% | 5% | 100% | 连续 5% |
| 20% | 20% | 100% | 直通 20% |
| 100% | 100% | 100% | 直通 100% |

脉冲幅度按圆形归一化，即 `方向 × A`；宿主按增量叠加，插件返回的是与原位置的差值。

## 参数

这些参数都是绑定级（`scope: binding`），在摇杆属性页的“插件配置”里逐个映射调整；没有统一的启用开关，取消摇杆上的插件绑定即恢复直通。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 最低脉冲幅度 | 5% | 低于此强度的输入按该幅度脉冲；高于则直通。必须高于下游死区，下游会缩放时要更高 |
| 脉冲宽度 | 4 ms | 每次脉冲持续的时间 |
| 输入死区阈值 | 0% | 低于此强度完全不输出，用于抑制漂移 |
| 缩放型下游补偿 | 关闭 | 开启后改用静态反死区映射，忽略最低脉冲幅度和脉冲宽度 |
| 下游死区 | 0% | 仅在缩放型下游补偿开启时使用，填写游戏或宿主的死区 |

## 缩放型下游补偿

如果游戏不只是截断死区，而是把死区以上的输入重新缩放，例如 `(a - 死区) / (1 - 死区)`，时间脉冲模式无法让补偿区和直通区保持同一斜率。此时在摇杆属性页勾选“缩放型下游补偿”，并把“下游死区”填成游戏实际值（如 20%）。

开启后插件不再脉冲，而是把输入静态重映射为：

```
输出 = 下游死区 + 输入 × (1 - 下游死区)
```

下游再把 `输出` 按 `(a - 死区) / (1 - 死区)` 缩放后，得到的强度正好等于输入，因此整个行程是同一斜率。该模式忽略“最低脉冲幅度”和“脉冲宽度”，只使用“下游死区”和“输入死区阈值”。

开启后游戏看到的强度等于物理输入，整条曲线是 1:1；相比游戏原来的死区缩放，25% 以上的输出也会抬高，整体灵敏度会变大，需要在游戏内适当降低灵敏度。

- 下游死区估小会残留一点死区，但不会在中心产生漂移；估大会把中心附近的轻微抖动放大成输出，需要按游戏实际值或略小填写。
- “输入死区阈值”只用于抑制硬件漂移，保持 0 或填 1%～2% 即可；把它填成 20% 会把 0～20% 直接清零，缩放补偿也就失效了。
- 如果游戏只是硬截断、不做缩放，保持本开关关闭，继续使用时间脉冲模式。

## 局限

- 输出粒度是一帧，无法输出半帧。脉冲宽度小于实际帧间隔时会被自动抬到一帧，否则低强度会被帧量化放大。
- 最低幅度必须高于下游死区，否则脉冲同样过不去。默认的 5% 只适合死区很低的游戏；常见 10%~25% 死区的游戏需要把这一项调到死区之上。
- 上面的“平均强度不变”只对下游死区之前的幅度成立。很多游戏会把死区以上的输入重新缩放，例如 `(a - 死区) / (1 - 死区)`；此时幅度 `m` 的脉冲只剩 `(m - 死区) / (1 - 死区)`。以死区 20%、最低幅度 25% 为例，脉冲实际只有 6.25%，补偿区增益约 0.25，而直通区增益是 1.25，边界处会出现约 5 倍的斜率跳变，手感上就是“中心像传统曲线，过 25% 突然变灵敏”。时间占比无法改变下游对每个采样值的缩放；要让整段斜率一致，开启“缩放型下游补偿”并把“下游死区”填成游戏实际值即可，也可以直接关闭游戏死区。继续使用时间脉冲模式时，把最低幅度调到远高于下游死区（如 50%~75%）可以减轻压缩，但脉冲幅度也会更大。
- 4 ms 脉宽、5% 最低幅度下：1% 输入约 4 ms 输出 + 16 ms 等待；0.5% 输入约 4 ms 输出 + 36 ms 等待。
- 下游若以 60 Hz 采样，短于约 17 ms 的脉冲可能被漏采，表现为偶尔一顿；长期平均值仍然正确。
- 输入若已被宿主死区清零，插件无法恢复那部分幅度，应把宿主死区调低或关闭。

## 安装

把 `time_deadzone` 文件夹复制到 **EXE 同级的 `plugins/offline/`** 下，重启程序；也可以通过“从文件安装”选择本目录的 `manifest.yaml`。

然后在摇杆属性页的“附加插件”中选择“基于时间的反死区 / 时间反死区摇杆”。配置示例：

```yaml
left_stick:
  plugin: {plugin: ecabea6e-4e13-4dd2-bc0d-9a5afc2ced14, id: stick}
```
