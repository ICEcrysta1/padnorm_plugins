# 时间反死区

默认把摇杆输入强度从“输出幅度”改成“输出时间占比”：输入低于游戏死区时，脉冲期间沿原方向输出该幅度，其余时间归零；输入达到游戏死区后直接直通。这样小幅输入也能越过下游死区；若下游只是把低于死区的值截断、不缩放，长期平均强度仍与输入一致。若下游会重新缩放死区以上的输入，可开启“缩放反死区”改用静态反死区映射。

## 原理

设输入强度为 `s`（向量长度），游戏死区为 `m`（脉冲幅度也取 `m`），脉宽为 `p`：

```
占空比 = s / m
周期   = p / 占空比 = p × m / s
```

每个周期输出 `p` 毫秒的 `m` 幅度，其余时间归零，下游死区之前的平均输出为 `m × (s / m) = s`。

- `s < m`：按占空比 `s / m` 脉冲输出。
- `s ≥ m`：直接直通；输入本身已达到死区，不再需要补偿。
- `s = m / 2`：脉宽等于等待间隔。

以 `m = 20%`、`p = 4 ms` 为例：

| 输入 | 占空比 | 输出 |
| --- | --- | --- |
| 2% | 10% | 4 ms 输出 + 36 ms 等待 |
| 5% | 25% | 4 ms 输出 + 12 ms 等待 |
| 10% | 50% | 4 ms 输出 + 4 ms 等待 |
| 20% | 100% | 连续 20% |
| 30% | 100% | 直通 30% |

脉冲幅度按圆形归一化，即 `方向 × m`；宿主按增量叠加，插件返回的是与原位置的差值。

## 参数

三个参数都是绑定级（`scope: binding`），在摇杆属性页的“插件配置”里逐个映射调整；没有统一的启用开关，取消摇杆上的插件绑定即恢复直通。输入死区由宿主统一处理，本插件不再单独设置。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 脉宽 | 4 ms | 每次脉冲持续的时间；缩放反死区开启时不生效 |
| 游戏死区 | 20% | 脉冲模式下作为脉冲幅度和直通阈值，建议略高于实际死区；缩放模式下作为下游死区 |
| 缩放反死区 | 关闭 | 开启后改用静态反死区映射，只使用游戏死区 |

## 缩放反死区

如果游戏不只是截断死区，而是把死区以上的输入重新缩放，例如 `(a - 死区) / (1 - 死区)`，时间脉冲模式无法让补偿区和直通区保持同一斜率。此时在摇杆属性页勾选“缩放反死区”，并把“游戏死区”填成游戏实际值（如 20%）。

开启后插件不再脉冲，而是把输入静态重映射为：

```
输出 = 游戏死区 + 输入 × (1 - 游戏死区)
```

下游再把 `输出` 按 `(a - 死区) / (1 - 死区)` 缩放后，得到的强度正好等于输入，因此整个行程是同一斜率。该模式只使用“游戏死区”，脉冲宽度不生效。

开启后游戏看到的强度等于物理输入，整条曲线是 1:1；相比游戏原来的死区缩放，死区以上的输出也会抬高，整体灵敏度会变大，需要在游戏内适当降低灵敏度。

- 游戏死区填实际值或略小：估小会残留一点死区，但不会在中心产生漂移；估大会把中心附近的轻微抖动放大成输出。
- 如果游戏只是硬截断、不做缩放，保持本开关关闭，继续使用时间脉冲模式。

## 局限

- 输出粒度是一帧，无法输出半帧。脉冲宽度小于实际帧间隔时会被自动抬到一帧，否则低强度会被帧量化放大。
- 脉冲模式下“游戏死区”建议略高于实际死区，否则脉冲同样过不去；死区很低的游戏要把它调低。
- 上面的“平均强度不变”只对下游死区之前的幅度成立。很多游戏会把死区以上的输入重新缩放，例如 `(a - 死区) / (1 - 死区)`；此时脉冲幅度 `m` 会被压成 `(m - 死区) / (1 - 死区)`，补偿区与直通区的斜率不一致。开启“缩放反死区”并把“游戏死区”填成实际值即可消除这个差异。
- 4 ms 脉宽、20% 游戏死区下：2% 输入约 4 ms 输出 + 36 ms 等待；5% 输入约 4 ms 输出 + 12 ms 等待。
- 下游若以 60 Hz 采样，短于约 17 ms 的脉冲可能被漏采，表现为偶尔一顿；长期平均值仍然正确。
- 输入若已被宿主死区清零，插件无法恢复那部分幅度，应把宿主死区调低或关闭。

## 安装

把 `time_deadzone` 文件夹复制到 **EXE 同级的 `plugins/offline/`** 下，重启程序；也可以通过“从文件安装”选择本目录的 `manifest.yaml`。

然后在摇杆属性页的“附加插件”中选择“时间反死区 / 反死区摇杆”。配置示例：

```yaml
left_stick:
  plugin: {plugin: ecabea6e-4e13-4dd2-bc0d-9a5afc2ced14, id: stick}
```
